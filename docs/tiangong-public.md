# Login-free TianGong historical-data search

On 2026-10-08 the public [TianGong data repository](https://github.com/tiangong-lca/data) was cloned at commit `c50cab7961e0b0ca11c26a600bd4c90fea6c6c32`. Its README calls it a historical snapshot, says GitHub releases are no longer maintained, and directs users to the platform for current exports. No account was needed for this GitHub clone. The public tree contains 4,132 ILCD process XML files and 25 LCIA method XML files. The entire database is not committed here; retrieval details are in [tiangong_manifest.json](../data/tiangong_manifest.json).

The process names were searched for `polyamide`, `nylon`, `polyoxymethylene`, `polycarbonate`, `silicone`, `brass`, `copper`, `stainless` and packaging terms. [Candidate metadata](../results/tiangong_candidates.csv) records IDs, versions, Chinese geography, reference years, reference output quantities and file hashes. The reference outputs listed there use the ILCD Mass property, whose reference unit is kg. Brass and refined copper are plausible material candidates, but their provider chains, allocation and LCIA flow matching remain unchecked. The nylon record produces industrial yarn, which is an inappropriate direct substitute for a molded kettle component. The organic-silicon record produces monomer, not finished silicone elastomer. No POM or PC production process was found in the 4,132 process names. PC and PA6/PA66 product flows occur in the flow catalog but have no matching process record in this snapshot, so a flow name alone cannot supply an impact.

The historical archive includes an [Environmental Footprint Climate change LCIA method](https://github.com/tiangong-lca/data/blob/c50cab7961e0b0ca11c26a600bd4c90fea6c6c32/tiangong_lca_data/lciamethods/6209b35f-9447-40b5-b68c-a1099e3674a0.xml), UUID `6209b35f-9447-40b5-b68c-a1099e3674a0`, version `01.00.000`, labeled GWP100 and “Baseline model of the IPCC 2021”. It is a **candidate method**, not an applied method: flow identities, unit conversions, fossil/biogenic handling and coverage have not been checked for a full kettle model. Its XML SHA-256 is `c0fe31d3c045ae85b64bd85a3bfa41e1f246d664e8f8d463005f37dee003a5a8`.

This search happened after the tagged independent audit and did not alter [independent.json](../results/independent.json). The historical records offer a login-free way to inspect TianGong candidates, but do not by themselves provide a complete, closed kettle supply chain or a valid GWP100 total.
