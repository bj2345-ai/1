# Background data search and decisions

Search date: 2026-10-08. The complete choices are in [matches.csv](../data/matches.csv); record metadata is in [dataset_records.csv](../results/dataset_records.csv).

## TianGong

The published `@tiangong-lca/cli@0.1.27` was installed temporarily via npm. The command `tiangong-lca search process --input /tmp/tiangong-search.json --json` used the query `polypropylene granulate production`. The CLI returned `SUPABASE_OAUTH_LOGIN_REQUIRED`; no usable session was available. The [TianGong data repository](https://github.com/tiangong-lca/data) says it is a historical snapshot and directs users to the [platform](https://lca.tiangong.earth/) to export current data. A subsequent login-free inspection of that public historical tree found candidate ILCD records and a GWP100 method; details are in [tiangong-public.md](tiangong-public.md). No current TianGong platform record was inspected or used. No credentials were copied into this repository.

## USLCI

The Federal LCA Commons datasets site and API guide returned HTTP 403 from this environment. The [official release index](https://github.com/FLCAC-admin/uslci-content/blob/dev/docs/release_info/release-downloads.md) was accessible. The September 2026 `.zolca` was downloaded and inspected as an openLCA Derby archive; the June 2025 JSON-LD release was chosen for auditable record-by-record parsing. Its verified URL, hash and release are in [manifest.json](../data/manifest.json). Search scanned all 962 process names in that ZIP using case-insensitive terms: `polypropylene`, `polyvinyl`, `polycarbonate`, `nylon`, `polyoxymethylene`, `acrylonitrile`, `silicone`, `brass`, `copper`, `stainless`, `corrugated`, `LDPE`, `polyamide`, and `acetal`. The [September 2026 release notes](https://github.com/FLCAC-admin/uslci-content/blob/dev/docs/release_info/press-release.md#2026-fall-quarter-september-30) say its electricity providers are linked through Commons Merged, which was not available in this environment; the September archive was not mixed into this June 2025 record audit.

Candidates include 304 flat rolled stainless coil, PP resin, PVC resin, ABS resin, LDPE resin and average corrugated product. These are candidate upstream materials, not verified cradle-to-gate contributions for finished kettle components. The USLCI PP injection molding record (`89a2b59a-1ca2-34f5-acc8-a8eaaa6fa870`, version `00.00.014`, Northern America, 1 kg molded part) was inspected as an alternative to PP resin plus separate molding. It embeds PP resin and molding electricity and cannot be added on top of a full PP resin burden for the same part. The 100% recycled corrugated record (`9c10be0f-e38e-4551-b8b5-eef65fa27dcc`, version `00.01.003`, US, 1 kg) was considered but not selected because the package's recycled content is unknown.

The only copper-named candidate is a `USLCI to USEEIO` bridge (`6373ec73-ca57-47bd-8284-2f3cc25b8637`, version `00.00.004`, 1 kg copper at regional storage). It was rejected as a standalone unit-process background because its USEEIO connection is external. No brass, nylon, POM, PC or silicone production process was found in the downloaded USLCI release. An absent named process here does not mean no such process exists in another database. The archive also lacks LCIA method records. Direct default-provider gaps found in the candidate processes are recorded in [provider_gaps.json](../results/provider_gaps.json). These are unresolved links, even where an alternative provider might exist.

No monetary proxy is used. Currency, price year and purchaser/basic-price basis are therefore not applicable.

The official June 2025 `U.S._electricity_baseline_v1.2025-06.0.zip` linked from the release index was also downloaded (SHA-256 `9fec32a8b5f75560c93d6a34986ee5e1166cd3d1cd257616172a3e041cab2815`). It is an openLCA matrix library (`A.npz`, `B.npz`, `INV.npy` and related metadata), not a drop-in JSON-LD process archive. No unverified join was made between its matrix indexes and the missing USLCI default-provider UUIDs. It also cannot fill the non-electricity material/provider gaps.
